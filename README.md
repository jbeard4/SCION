# SCHVIZ2

## Getting started

```bash
npm install
bower install
open test.html
```

## Example Usage

```javascript
var schviz = new SCHVIZ(parent : DOMNode);

schviz.renderSCJSON(jsonDoc : scjson)
schviz.updateKgraph(kgraph : kgraphJson)
```

See `test.html` for example usage.
